Invoice to JSON API

Extract structured JSON from invoices, receipts, resumes, bank statements and more - with OCR, in English and Vietnamese.

Get your API key on RapidAPI API docs

What it does

Send raw text, an image or a PDF, and get back clean JSON: numbers, dates, vendor, totals and line items. No LLM key required. Typical response under 1 second.

Supported documents

DocumentEndpoint
InvoicePOST /v1/invoice/extract
ReceiptPOST /v1/receipt/extract
Resume / CVPOST /v1/resume/extract
Bank statementPOST /v1/bank-statement/extract
Purchase orderPOST /v1/purchase-order/extract
ContractPOST /v1/contract/extract
Business cardPOST /v1/business-card/extract
Utility billPOST /v1/utility-bill/extract

Every endpoint has a /base64 variant for images and PDFs (OCR included).

Quick start

curl -X POST https://invoice-extract-api-4eq9.onrender.com/v1/invoice/extract -H "Content-Type: application/json" -d '{"content": "INVOICE #12345 Total: 100.00 USD"}'

Why developers use it

  • No LLM key required - works out of the box
  • Bilingual English / Vietnamese
  • OCR for images and PDFs included
  • Fast: heuristic extraction in about 1 ms
  • Simple JSON in / JSON out

Use cases

  • Accounting automation and bookkeeping
  • Expense management apps
  • E-commerce order and receipt parsing
  • KYC / onboarding from business cards and IDs
  • Loan and bank-statement analysis
